\title{Balade: Lifelike Cursor Behavior from State Machines and Mathematics}
\author{\IEEEauthorblockN{Fox3000foxy}\IEEEauthorblockA{Independent Researcher\\fox3000foxy@users.noreply.github.com}}
\maketitle
\begin{abstract}
Balade is a browser extension that places autonomous animated cursors on web
pages. No neural network is involved: every behavior is a coroutine (a
generator used as a state machine) driven by classical mathematics. This paper
documents the exact laws and constants shipped in the code (I--III), the
behaviors from v0.1 to v1.3.1 (IV), the formula substitutions that made them
fast (V), negative results (VI) and engineering lessons (VII). All constants
are the shipped values from \texttt{src/core/Config.js}.
\end{abstract}

\section{Behaviors as Coroutines}
Each cursor runs a generator \texttt{*run(cursor)} yielding the frame time
step. One requestAnimationFrame loop pumps all cursors with a shared clock.
Composition uses \texttt{yield*}; state lives in generator locals. One bad
frame never kills the loop: try/catch around step and render, rAF always
re-armed.

\section{Duration: Fitts's Law}
\begin{equation}
T = \frac{\mathrm{clamp}(0.08 + 0.085\,\log_2(1 + D/W),\, 0.12,\, 0.75)}{v}
\end{equation}
$D$ distance, $W$ target width ($\max(4, W)$ floor), $v$ speed multiplier.
Example at $v=1$, $W=24$: $D=100 \Rightarrow 0.27$\,s; $D=800 \Rightarrow 0.51$\,s.

\section{Profile: Minimum Jerk with Time Warp}
\begin{equation}
s(t) = 10t^3 - 15t^4 + 6t^5, \qquad u = s(t^q),\; q \in [0.68, 0.85]
\end{equation}
Each cursor keeps its own $q$ and first-try precision for life (motor
signature). Correction probability 0.75 (0.15 for precise cursors), pause
$[0.02, 0.08]$\,s, correction speed $0.8\times$.

\section{Paths: Turtle Arcs and Similarity}
Traced turtle-style along circular arcs, then similarity-mapped onto the
target. Short trips ($<90$\,px) stay nearly straight; curvature reaches full
amplitude at 420\,px. Styles: arc 0.45, S 0.25, hook 0.2, wave 0.1. Resolution
24 points. Progress sampled into 64-entry curves per gesture ($u=\mathrm{minjerk}(t^q)$,
error $<5\times10^{-4}$).

\section{Swarm, Sound, Cognition}
Reynolds steering: breathing orbit, 3-lobe rosace, swirl
$\tanh(3\cos(0.11\,t))$; neighbor alignment 70/30 within 80\,px. Sound:
pentatonic (0, 2, 4, 7, 9) from MIDI 72 (C5), pan $1.6\,x/L-0.8$ clamped to
$\pm0.8$. Habits: first-order Markov chains per site; satiety decays over
10\,min; novelty pressure. Social roles: leader 15\%, follower 30\%,
loner 15\%.

\section{Behaviors v0.1 to v1.3.1}
Wandering, ghost typing, voices; themes (Ghost default), attention, meetings;
per-site settings, dark adaptation, anticipation; customization, tag game,
focus mode, WebM recording; i18n EN/FR (145 keys), cross-page persistence;
ambient features (reading ambiance, scroll hint, guided tour, companion,
contrast inspector, site weather); cognition, roles, moods, teasing;
freeze fixes and modal dimming.

Deliberately not optimized: Fitts \texttt{log2} once per gesture.

\section{Negative Results}
Sine table lost $3\times$ (memory $>$ FPU). Taylor-5 slower and wrong.
Cosine pre-filter lost (48 vs 38\,ms). Satiety early-return reverted to a
remark weight. Visits in the version field crashed inspections: separate map.

\section{Engineering Lessons}
Cache poisoning, double-injection race, key collisions, dead placeholders,
the loop must survive. Method: hypothesis, benchmark, keep or reject with
numbers, document both.

\section{Conclusion}
Lifelike behavior needs no learning: composable state machines plus the
right classical formulas---with exact, benchmarked substitutions---are
enough.
